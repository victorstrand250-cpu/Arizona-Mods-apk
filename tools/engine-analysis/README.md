# Инструменты разбора libag-client.so

Написаны под конкретную задачу: движок собран stripped, готовые
дизассемблеры на 6.6 МБ кода дают слишком много шума, а нужны были
точечные ответы. Результаты разбора — в [`../../docs/ENGINE_MAP.md`](../../docs/ENGINE_MAP.md).

Всем скриптам нужен путь к `libag-client.so` внутри — правьте константу
`SO` вверху файла.

| Файл | Что делает |
|---|---|
| `xref.py` | перекрёстные ссылки: разбирает пары `ADRP+ADD` и `ADRP+LDR` по всему `.text` и складывает в индекс «какой код обращается к какому адресу» |
| `plt.py` | сопоставляет заглушки PLT с именами импортов через `.rela.plt`; в stripped-библиотеке имена импортов остаются и служат зацепкой |
| `findwin.py` | находит вызовы `ImGui::Begin` и восстанавливает заголовок окна и адрес флага-включателя |
| `fields.py` | карта полей структуры игрока: от места, где код берёт указатель из массива, вперёд по инструкциям собирает обращения по смещениям |
| `glargs.py` | ищет глобалы, уходящие в вызовы GL четвёртым аргументом (для матриц не сработало — движок пишет команды GL в буфер) |

Порядок запуска: сначала `xref.py <so> refs.pkl`, он кладёт индекс ссылок,
которым пользуются остальные.
